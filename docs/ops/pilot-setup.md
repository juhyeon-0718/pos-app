# 파일럿 첫 설정 순서 (B-10)

처음 한 번, 비어 있는 DB에서 아래 순서대로 따라 합니다. 각 단계 끝에 "이렇게 나오면 성공"을 적어 두었습니다.
같은 명령을 다시 실행해도 데이터가 중복되지 않습니다. (단, 4단계 엑셀 적재는 아래 안내를 먼저 읽어 주세요.)

## 시작 전에 준비할 것
- 이 컴퓨터에 `backend/.env` 파일이 있어야 합니다. 안에 `DATABASE_URL`(DB 주소), `JWT_SECRET`(로그인 암호키, 32자 이상 아무 문자열), `ENV=prod`가 들어 있어야 합니다. 이 파일과 비밀번호는 채팅이나 git에 올리지 않습니다.
- PowerShell을 열고 `backend` 폴더로 이동합니다. 파이썬 가상환경(venv)이 있으면 먼저 켭니다.

```
cd C:\juehyeon\pos-app\main\backend
```

## 1단계. DB 표 만들기 (마이그레이션)
```
python -m alembic upgrade head
```
이렇게 나오면 성공: `Running upgrade ... -> ...` 줄이 이어지다가 오류 없이 끝납니다. 이미 최신이면 `Will assume transactional DDL.`만 나오고 끝납니다.

확인:
```
python -m alembic current
```
이렇게 나오면 성공: `337a1c1c7083 (head)` (마지막 줄 끝에 `(head)`가 붙어야 합니다. 앞의 숫자는 이후 작업으로 바뀔 수 있습니다.)

## 2단계. 사장 계정과 테이블 QR 만들기 (bootstrap)
사장 비밀번호는 **본인이 직접 입력**합니다(8자 이상). 화면에 글자가 보이지 않는 것이 정상입니다.
테이블 수(`--tables`)와 손님 화면 주소(`--base-url`)는 매장에 맞게 바꿉니다. QR 주소 파일(`--csv-out`)은 git 저장소 밖에 저장합니다.

```
python scripts/bootstrap_store.py --tables 10 --base-url https://우리가게주소 --csv-out C:\Users\본인이름\Desktop\table-qr-urls.csv
```
입력창이 나옵니다.
```
사장 비밀번호:
한 번 더 입력:
```
이렇게 나오면 성공:
```
사장 계정을 만들었습니다.
테이블 10개의 QR 주소를 C:\Users\본인이름\Desktop\table-qr-urls.csv에 썼습니다. 이 파일은 커밋하지 마세요.
```
- 사장 로그인 아이디는 기본 `owner`입니다. 바꾸려면 `--owner-username 아이디`를 붙입니다.
- **다시 실행하면** `사장 계정이 이미 있어 건너뜁니다.`가 나오고 비밀번호는 묻지 않으며 아무것도 바뀌지 않습니다. 테이블과 QR 주소도 그대로입니다.
- QR 주소 파일(`table-qr-urls.csv`)은 엑셀로 열 수 있습니다. 열마다 `table_no`(테이블 번호), `table_id`, `url`(그 테이블의 접속 주소)입니다. `url`을 QR 코드로 바꿔 테이블에 붙입니다. QR 이미지 만들기는 이 스크립트가 하지 않습니다. 이 파일은 비밀 정보와 같으니 남에게 보내지 말고, 다 쓰면 지웁니다.
- 테이블 수를 늘리고 싶으면 `--tables 12`처럼 다시 실행합니다. 기존 1~10번은 그대로이고 11~12번만 새로 생깁니다.

로그인 확인: 손님이 아닌 사장 화면 주소(`/owner`)로 들어가 `owner`와 방금 입력한 비밀번호로 로그인합니다. 사장 화면이 열리면 성공입니다.

## 3단계. 직원·주방 계정 만들기
계정마다 한 번씩 실행합니다. 비밀번호는 그 계정을 쓸 사람과 정해서 직접 입력합니다.
```
python scripts/bootstrap_store.py --add-user staff1 --role staff
python scripts/bootstrap_store.py --add-user kitchen1 --role kitchen
```
각각 비밀번호 입력창이 나옵니다. 이렇게 나오면 성공:
```
사장 계정이 이미 있어 건너뜁니다.
staff 계정 'staff1'을(를) 만들었습니다.
```
(주방은 `kitchen 계정 'kitchen1'을(를) 만들었습니다.`)
- 첫 줄의 `사장 계정이 이미 있어 건너뜁니다.`는 정상입니다.
- 같은 아이디로 다시 실행하면 `이미 있어 건너뜁니다.`가 나오고 비밀번호는 바뀌지 않습니다. 비밀번호를 바꾸려면 사장 화면이 아니라 개발팀에 요청해 주세요(현재 화면에는 없습니다).
- `staff`는 홀 직원, `kitchen`은 주방입니다. 각자 로그인해서 직원 화면, 주방 화면이 열리는지 확인합니다.

## 4단계. 메뉴·식재료 엑셀 올리기 (Q-04 스크립트)
> ⚠ 이 단계는 아직 사용할 수 없습니다. 엑셀 검증·적재 스크립트(`import_store_data.py`)가 아직 main에 들어오지 않았고, 현재 버전은 DB에 실제로 저장하지 않는 시험용 연결 상태입니다. 최유나 님의 Q-04 PR이 머지되고 실제 저장 연결이 끝나면 이 단계의 명령과 기대 출력을 확정해 다시 적습니다. 그때까지 아래는 예정된 형태입니다.

예정된 명령(확정 아님):
```
python scripts/import_store_data.py C:\Users\본인이름\Desktop\store-data.xlsx
```
- 엑셀 파일은 개인 폴더에 두고 git에 올리지 않습니다.
- 성공하면 만든 메뉴·식재료 개수가 한 줄로 나오고, 오류가 있으면 "몇 번째 줄이 문제인지" 목록이 나옵니다. 오류가 있으면 아무것도 저장되지 않는지(전부 저장 또는 전부 안 함)는 확정 후 이 문서에 적습니다.

순서 요약: 1단계(표 만들기) → 2단계(사장·테이블) → 3단계(직원·주방) → 4단계(엑셀). 3단계와 4단계는 순서를 바꿔도 되지만, 2단계 전에 4단계를 하지 마세요.

## 문제가 생겼을 때
- `DATABASE_URL 환경변수가 필요합니다`: `backend/.env`가 없거나 `DATABASE_URL`이 비어 있습니다.
- `JWT_SECRET 환경변수가 필요합니다`: `.env`에 `JWT_SECRET`을 넣어야 합니다.
- `비밀번호는 8자 이상이어야 합니다`: 더 긴 비밀번호로 다시 실행합니다.
- `비밀번호가 서로 다릅니다`: 두 번 입력이 달랐습니다. 처음부터 다시 실행합니다.
- 그 밖의 오류 화면은 비밀번호가 보이지 않는지 확인한 뒤 통째로 개발팀에 보내 주세요.
