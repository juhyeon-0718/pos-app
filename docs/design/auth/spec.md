# U-07 로그인 화면 명세 (시안 단계, U-03)

상태: 메인 화면 시안만. 기본·로딩(로그인 중)·오류(로그인 실패)·비활성 상태는 U-07 상세 명세에서 정의한다.
프로토타입: `prototype/login.html` (1024×768 기준, 모바일에서도 카드가 폭에 맞게 줄어듦).

## 구성
- 가운데 카드(최대 420px): 로고(전체형), 제목 "로그인", 안내 한 줄, 아이디·비밀번호 입력(높이 56px), "로그인" 버튼(56px, 전체 너비), 하단 손님 안내 한 줄.
- 입력창 라벨은 항상 보이게 둔다(placeholder 대체 금지). 자동완성(`username`, `current-password`) 유지.

## 사용 토큰
`--size-touch-lg`, `--font-size-3xl`, `--shadow-md`, 공용 Button·Card(U-03 components).

## 데이터 (openapi.yaml 기준)
`POST /auth/login` 본문 `username`, `password`. 응답 `access_token`, `token_type`, `role`(역할별 분기는 상위에서).

## 계약 요청
없음. 오류 문구는 계정 존재 여부를 알려 주지 않도록 "아이디 또는 비밀번호가 올바르지 않습니다."를 유지한다.

## 완료 조건 (구현자, 잠정)
1. 오류는 `role="alert"` 배너, 로그인 중에는 버튼 비활성 + 스피너 + 글자.
2. 비밀번호 값은 화면·로그에 남기지 않는다.
3. 토큰 변수만 사용.
